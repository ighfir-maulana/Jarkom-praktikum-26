## 📌 Deskripsi Proyek
Repositori ini adalah dokumentasi perjalanan praktikum saya dalam mata kuliah **Jaringan Komputer** di **Laboratorium Informatika Telkom University**. Fokus utama repositori ini adalah eksplorasi mendalam terhadap arsitektur internet menggunakan pendekatan *Top-Down*, mulai dari *Application Layer* hingga *Physical Layer*.

- **Network Analyzer:** Wireshark (Packet Sniffer)
- **Programming:** Python 3.x (Socket Programming)
- **Driver:** Npcap / WinPcap
- **Operating System:** Windows 10
- **Reference Book:** *Computer Networking: A Top-Down Approach* (Kurose & Ross)
